## Ask

Center a fixed-size box inside its parent, both ways.

## Look for

- Uses grid place-items or flex with both alignments
- Knows margin auto centers horizontally
- Checks the parent has a height

## Follow-ups

- What changes if the box has no fixed size?
- How would you center text inside it?
