## Ask

Center a fixed-size box inside its parent, both ways.

## Look for

### junior

- Uses grid `place-items` or flex with both alignments
- Checks the parent has a height

### mid

- Explains why `margin: auto` centers horizontally but not vertically
- Picks one approach and says when the other fits better #judgment

### senior

- Asks what the box sits in before choosing a layout #judgment

## Follow-ups

- What changes if the box has no fixed size?
- How would you center text inside it?
